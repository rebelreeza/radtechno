AI Token Costs

Internal reference. Per-use-case token estimates across all 31 AI workflows, with realistic monthly ranges by deployment stage.

The full use case map spans 31 AI-powered workflows across 7 categories. Many run continuously across 70 stores — per-order triggers, daily monitoring, per-creator scoring — so volume adds up fast as more use cases go live. The key cost lever is model selection: route high-frequency structured tasks to Haiku, reserve Sonnet for reasoning-heavy synthesis. Below: per-use-case estimates for the foundation tier, then realistic monthly ranges by deployment stage.

Use case Model Volume / mo Tokens / call Est. monthly cost Notes
CEO Dashboard / Portfolio View No AI – BI tool only — — $0 Metabase queries BigQuery directly. Real-Time Portfolio View is a dashboard, not a generation task.
Structured Q&A (text-to-SQL) Claude Haiku Recommended ~300 queries ~2,000 avg ~$0.50/mo Haiku handles schema-aware SQL well. Escalate to Sonnet only when query complexity regularly fails.
Knowledge Q&A (RAG) Claude Sonnet ~100 queries ~4,000 avg (incl. context) ~$1.50/mo Context chunks add tokens. Sonnet justified — doc reasoning is where quality matters.
Automated reports (weekly, per store) Claude Haiku ~280 reports (70 stores × 4 wks) ~5,000 avg ~$1.12/mo Scheduled summarization scales linearly with store count. Haiku is more than capable.
Inventory alerts / anomaly detection Claude Haiku ~5,000 checks (70 stores, daily) ~500 avg ~$2/mo High volume, simple pattern matching. The cost is per-check, and 70 stores running daily adds up to meaningful volume.
Margin leakage detection (continuous) Claude Haiku ~2,100 scans (70 stores, daily) ~3,000 avg ~$5/mo Runs continuously against BigQuery. Per-scan cost is low; frequency across 70 stores makes this the highest-volume Haiku task.
Post-purchase / win-back triggers Claude Haiku ~3,000 events (order-triggered) ~800 avg ~$2.40/mo Triggered per qualifying order or lapsed customer event. Volume depends on drop frequency across the portfolio.
Cross-store campaign pattern matching Claude Sonnet ~40 analyses ~8,000 avg ~$4/mo Flagship use case. Rich multi-store synthesis warrants Sonnet. Runs post-campaign, not continuously.
Campaign brief generation Claude Sonnet ~40 briefs ~5,000 avg (output-heavy) ~$4/mo Output-heavy generation at quality threshold. Cache brief templates to avoid re-generating boilerplate.
Creator health scores + debrief reports Claude Sonnet ~280 (70 creators × weekly) ~4,000 avg ~$5/mo Per-creator scoring + post-campaign debrief generation. Quality matters for creator-facing outputs.
Launch readiness scoring Claude Sonnet ~30 launches ~4,000 avg ~$1/mo Pre-launch multi-signal assessment. Runs per launch event, not continuously.
Revenue anomaly explainer Claude Sonnet ~50 events ~5,000 avg ~$1.50/mo Event-triggered, not continuous. Only fires when anomaly detection (Haiku) escalates a flag.
Remaining use cases (fit predictor, return intel, trend signals, bundle analysis, etc.) Haiku / Sonnet mix Varies Varies ~$10–30/mo ~20 additional use cases across Creator Intelligence, Product Intelligence, Audience Intelligence, and Risk Detection. Individually cheap; collectively meaningful at full deployment.
Realistic monthly token spend by deployment stage:
Stage Active use cases Est. monthly cost What's running
Early (months 1–3) 4–6 $5–15/mo SQL Q&A, RAG, weekly reports, inventory alerts, anomaly detection
Growing (months 4–9) 12–18 $40–100/mo + campaign matching, brief generation, creator scoring, post-purchase triggers, margin monitoring
Full deployment (12+ months) 25–31 $150–400/mo All 31 use cases live, full 70-store volume, continuous monitoring running around the clock

At full deployment, $150–400/mo in AI token spend is generating outputs that would otherwise require multiple analyst hours per week per store. The ROI math is straightforward. The cost pressure to watch: context window bloat (stuffing too much into prompts) and over-indexing on Sonnet for tasks Haiku handles fine — both controllable with intentional system design from day one.
