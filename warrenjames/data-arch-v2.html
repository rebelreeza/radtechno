Operational Sources - live, real-time

Shopify - 40 Stores

Orders, customers, payments, inventory availability. Storefront behavior, discount attribution, campaign UTMs. Each store is a separate instance.

orders → ← inventory
real-time sync

Odoo ERP

Inventory management, purchase orders, fulfillment, accounting, vendor management. Source of truth for what is actually in stock.

goods received

Suppliers / Manufacturers

Physical inventory arrives. PO confirmation into Odoo updates on-hand quantities, which then pushes to Shopify availability.

Document sources

SOPs, Contracts, Briefs

Institutional knowledge that lives outside databases. Ingested and embedded on upload or schedule. Not operational - analytical and contextual.

Storage Layer

BigQuery

Read-only analytical warehouse. Append-only historical record of orders, inventory, financials, store performance. Never writes back to Odoo or Shopify. Native Anthropic integration via Vertex AI.

Pinecone

Vector store. Document chunks embedded and indexed for semantic search. Retrieves relevant context before AI generates a response. Free tier covers WJ's current doc volume.

AI & Consumption Layer - where value is delivered

AI Orchestration Layer

Routes each query to the right source. SQL against BigQuery for structured data questions. Vector search against Pinecone for document and context questions. Can combine both in one response. Implemented as Claude tool-use, LangChain, or LlamaIndex - code, not a paid service.

routes to ▼

CEO Dashboard

All stores in one view via Metabase (self-hosted, free) connected to BigQuery. No manual reports.

Structured Q&A

Natural language to SQL. "Top 5 SKUs last week across all stores?" Answered in seconds.

Knowledge Q&A (RAG)

Questions that live in docs, not data. SOPs, contracts, briefs, historical context.

Automated Reports

Scheduled BigQuery queries emailed weekly to CEO and store managers.

AI Agents / Alerts

Reorder alerts, anomaly flags, commission processing via n8n or Make.

Working principles - tentative

✓ Odoo is inventory source of truth ✓ Odoo pushes inventory to Shopify ✓ Shopify pushes orders to Odoo ✓ ETL pulls from both independently ✓ AI reads from BigQuery only ✓ BigQuery is append-only, historical ✗ BigQuery never pushes to Odoo or Shopify ✗ AI never writes to production systems ✗ Never run analytics against Odoo directly ✗ No Supabase needed - no custom apps yet
